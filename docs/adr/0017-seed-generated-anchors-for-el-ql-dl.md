# Seed-generated anchors for the EL, QL, and DL correctness scales

Status: accepted

The EL, QL, and DL correctness anchors are the datasets generated by the
official generator at the paper-reported configuration already pinned for RL
by ADR 0015: `kracr/owl2bench` revision
`5a27536c8e7f7621b34c61c8a57ed9eb63e7829a`,
`java -jar OWL2Bench.jar 1 <PROFILE> 1` (one university, seed 1), staged as:

- `staged/0006_UNIV-BENCH-OWL2DL-seed1-u1.owl` — sha256
  `fce9e2c1fa58ffd8bd5deb7de224c1f4a7d8c0eec0c49dce0d42491e1854ed77`
  (50,845 axioms per the generator log)
- `staged/0007_UNIV-BENCH-OWL2EL-seed1-u1.owl` — sha256
  `49ac036c92153c0995f009ffea03d9843372eef5ffa29fd93f6533f6165f62c1`
  (50,755 axioms)
- `staged/0008_UNIV-BENCH-OWL2QL-seed1-u1.owl` — sha256
  `d2c5037f49f8a71488b3e2e2b8d82057b18bda931319eb4b7cf3d09a41e17d9c`
  (50,813 axioms)

Each anchor was generated twice from the preserved pinned jar and verified
byte-identical (same evidence standard as ADR 0015's RL anchor). All three
carry instance-rich ABoxes (~3.7k named individuals, ~5.3k `takesCourse`
assertions), so oracles over them are not vacuous — the reason the older
TBox-dominant samples 0001–0003 were rejected for RL remains valid here and
they stay as pipeline-validation evidence only. The generator jar used is the
one preserved from the RL anchor run
(`artifacts/tableauxx/retention-20260907/tmp-preserved/tableauxx-owl2bench.9JJ9KD/repo/OWL2Bench.jar`,
run from its repository directory), matching the pinned revision recorded in
the staged manifest.

## Consequences

Derived-oracle derivations for EL, QL, and DL run against these anchors when
those profiles extend; case identity carries each dataset id and sha256.
Known follow-up gaps recorded at staging time: the reasoner's RDF/XML parser
currently rejects the DL and EL anchors on blank-node class expressions
(`unsupported RDF/XML class expression in deferred class edge`), and the
derivation procedure's rule table is RL-only — extending it (including the
construct-dependent queries 006/017/018) is the decision the procedure doc
already pins. The expected vocabulary-split shape (TBox under `xml:base`,
ABox under the generator prefix) carries over and the dominant-ABox
namespace policy (ADR 0016) applies unchanged.
